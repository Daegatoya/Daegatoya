### 🚀 Featured Projects

#### 🧩 ALANA — Interpreted Programming Language

A personal interpreted programming language written in **C#**.

Exploring the fundamentals of language design, including:

- Lexical analysis and tokenization
- Abstract Syntax Trees (AST)
- Expression evaluation and operator precedence
- Variables and interpreter execution

**Tech:** `C#` `.NET` `Language Design`

#### 💻 BarelyOS — Hobby Operating System

A personal operating system project written in **C++**, created to explore low-level programming.

Current areas of experimentation:

- Kernel development
- Bootloading with Limine
- Framebuffer graphics
- Basic terminal and text rendering

**Tech:** `C++` `Clang` `Limine` `x86-64`
